# filtros-instagram
Aplicação web simples e interativa, com HTML, CSS e Javascript, inspirada na interface do Instagram, com foco na aplicação de filtros em imagens, semelhantemente ao próprio Instagram. A proposta é replicar a experiência visual, aplicando filtros gráficos em imagens selecionadas do dispositivo do usuário.
